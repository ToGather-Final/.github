# ToGather
🧶 [ToGather] 공동 목표 달성을 위한 그룹형 주식 투자 서비스

**기획 의도**:
- 공동 자금 관리 수요 증가와 모임통장 확산에 따른 자산 성장 수단의 필요성
- 소수점 거래를 통한 소액 공동 투자 및 자산 증식의 실현
- 투자 수익의 QR 결제 연계를 통한 공동 자금 활용 편의성 강화

## 🧭 프로젝트 개요

### 1️⃣ 기획 의도
- 모임통장에 쌓인 공동 자금을 함께 불릴 수 있는 **그룹형 소수점 투자 서비스 제공**  
- **투표 기능**을 통한 그룹원 간의 **투명한 의사결정 구조 구현**  
- **페이 QR 결제**를 통한 **간편한 공동 자금 사용 환경 제공**

<br/>

### 2️⃣ 기능 소개

1. 🛰 **그룹형 투자**
   - 투자 계좌 개설 후 그룹을 생성하여 참여  
   - 매매 규칙 설정 및 유의사항 확인 가능  

2. 🗞 **포트폴리오**
   - 목표 달성률과 예수금 현황 시각화  
   - 전체 순자산 및 보유 종목 상세 정보 확인  

3. 📈 **주식 정보**
   - 보유 종목 및 주식/ETF 리스트 제공  
   - 실시간 **주가 차트 및 호가창 조회** 기능  

4. 🔔 **소수점 매매 제안**
   - **매수:** 그룹원별 체결 금액이 정수가 되도록 반올림해 자동 조정  
   - **매도:** 정수 단위로 버림 처리 후 남은 금액을 수수료로 차감  

5. 🗳 **투표**
   - 제안 등록 후 찬성/반대 투표를 통해 매매 결정  
   - 결과는 **리스트/캘린더 뷰** 형태의 히스토리에서 확인 가능  

6. 💰 **페이 서비스**
   - QR 코드 스캔을 통한 간편 송금  
   - 페이머니 충전 및 거래 내역 조회 기능  

<br/>

### 3️⃣ 기대 효과

#### ⚙️ 기술적 기대 효과
1. **실시간 데이터 처리 및 인프라 운영 역량 강화**  
   - User / Pay / Trading / Vote Service 분리 기반 **MSA 설계 경험**  
   - **WebSocket 실시간 데이터 스트림** 구현을 통한 호가 정보 처리  
   - **AWS S3, EC2, GitHub Actions** 기반 **CI/CD 파이프라인 구축 경험**

2. **확장 가능한 서비스 구조 설계 능력 향상**  
   - 도메인 단위의 명확한 분리  
   - 서버-클라이언트 간 통신 구조에 대한 이해도 증진  

#### 💡 사회적 기대 효과
1. **모임 자금의 효율적 운용**
   - 저금리 예·적금 대비 적극적인 자금 운용 수단 제공  

2. **정산 스트레스 해소**
   - 외부 앱 이동 없이 ToGather 내에서 **투자–결제–정산까지 일원화된 경험 제공**
