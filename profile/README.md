# ToGather
🧶 [ToGather] 공동 목표 달성을 위한 그룹형 주식 투자 서비스

**기획 의도**:
- 공동 자금 관리 수요 증가와 모임통장 확산에 따른 자산 성장 수단의 필요성
- 소수점 거래를 통한 소액 공동 투자 및 자산 증식의 실현
- 투자 수익의 QR 결제 연계를 통한 공동 자금 활용 편의성 강화

## 프로젝트 개요

### 1️⃣ 기획 의도
- 모임통장의 공동 자금을 불릴 수 있는 그룹형 주식 소수점 투자 서비스 제공  
- 투표 기능을 통해 그룹원 간 투명한 의사결정 가능
- 페이 QR 서비스를 통해 간편한 모임 자금 사용 

<br/>

### 2️⃣ 기능 소개

1. 🛰 **그룹 생성을 통한 투자**  
   - 투자 계좌 개설 후 그룹 생성을 통한 참여  
   - 매매 규칙 선택 및 유의사항 확인

2. 🗞 **포트폴리오**  
   - 목표 달성률 시각화 및 예수금 제안 기능 제공
   - 전체 순자산, 보유 종목 상세 정보 확인 가능

3. 📈 **주식 정보 제공**  
   - 보유 종목 및 주식/ETF 리스트  
   - 주가 차트 및 실시간 호가 확인 

4. 🔔 **소수점 매매 제안**  
   - 매수: 그룹원 인당 체결 금액이 정수가 되도록 반올림하여 매수 가격을 자동 조정 
   - 매도: 그룹원 인당 체결 금액이 정수가 되도록 버림하고, 버림된 금액은 수수료로 차감

5. 🔉 **투표**  
   - 제안 조회에서 찬성/반대 투표 진행을 통해 투명한 의사결정 구조 제공
   - 투표 가결 이후 매매 진행
   - 내역은 히스토리에서 리스트/캘린더 뷰로 확인 가능

6. 💰 **페이**
   - QR코드 스캔을 통해 송금 진행
   - 페이머니 충전 및 거래 내역 조회 가능

<br/>

### 3️⃣ 기대효과

#### 📱 [기술적 기대효과]
1. **실시간 데이터 처리 및 인프라 이해도 향상**  
   - User, Pay, Trading, Vote Service를 분리한 MSA 기반 백엔드 설계 경험  
   - WebSocket 연동을 통한 실시간 호가 확인 시스템 구축  
   - AWS S3, EC2, GitHub Actions 기반의 CI/CD 파이프라인 구성 경험

2. **확장 가능한 서비스 구조 설계 역량 강화**  
   - 
   - 도메인 단위 분리 및 서버-클라이언트 구조 이해도 향상  

#### 🧩 [사회적 기대효과]
1. **모임 자금의 효율적 운용**  
   - 낮은 금리의 예/적금 보다 적극적으로 모임 자금을 운용할 수 있는 기능 제공

2. **정산 스트레스 해소**  
   - 모임 투자 자금을 타 어플로 이동하지 않고도 ToGather내의 페이 서비스로 정산할 수 있도록 편리한 환경 제공
