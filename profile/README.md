# ToGather
📊 [ToGather] 공동 목표 달성을 위한 그룹형 주식 투자 서비스

**기획 의도**:
- 공동 자금 관리 수요 증가와 모임 통장의 인기가 증가하고 있으나, 자산을 키우기에는 한계가 존재함
- 소수점 거래를 활용하여 함께 투자하고 자산을 키워 공동 자금 목표를 달성할 수 있음
- 목표 달성 이후에는 QR 결제 기능을 통해 공동 자금을 간편히 사용할 수 있음
